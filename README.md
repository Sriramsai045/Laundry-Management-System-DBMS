# Laundry Management System - DBMS Project

This project is a database system designed for managing a college hostel laundry service.

## Features
- Student registration and management
- Laundry order tracking
- Membership validation
- OTP generation for laundry collection
- Automatic return date calculation
- Maximum laundry item limit control

## Database Concepts Used
- Tables
- Primary Key and Foreign Key Constraints
- Check Constraints
- Triggers
- Views
- Subqueries

## Tables in the System
- Student
- Membership
- Laundry_Order
- Laundry_Item
- Item_Type
- System_User
- Laundry_OTP

## How to Use
1. Import the SQL file into MySQL.
2. Execute the script `college_laundry_db_backup.sql`.
3. The database schema and sample data will be created automatically.
